# ResQTwin

## AI-Powered Disaster Management & Intelligent Evacuation Platform

ResQTwin is an AI-powered disaster management platform that creates a
digital twin of an environment to simulate disasters, analyze risks,
optimize evacuation routes, track crowd movement, coordinate rescue
operations, and provide actionable information to government
authorities and citizens.

## Key Features

- Digital Twin Simulation
- AI-Based Disaster Risk Analysis
- Intelligent Evacuation
- Real-Time Crowd Tracking
- Rescue Coordination
- Government Dashboard
- Citizen/User Dashboard
- Map-Based Visualization

## Technology Stack

- Frontend: React
- Backend: TypeScript
- AI/ML
- Database
- Mappls
